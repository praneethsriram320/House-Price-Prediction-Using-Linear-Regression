# House Price Prediction Using Linear Regression

## Project Overview
This project predicts house prices using the California Housing dataset and the Linear Regression algorithm.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Project Steps
- Load the dataset
- Preprocess the data
- Encode categorical features
- Split the dataset
- Train the Linear Regression model
- Evaluate the model
- Predict house prices

## Result
The model successfully predicts house prices and is evaluated using MAE, MSE, RMSE, and R² Score.
